## What I Build

I work where product engineering, AI systems, and polished interfaces meet. My focus is simple: useful software that feels sharp, handles real workflows, and does not fall apart after the prototype stage.

- **Full-stack products:** production web apps with clean flows, typed backends, and UI details that make complex tools easier to use.
- **AI workflows:** retrieval, citations, tool use, and product guardrails for grounded AI-assisted software.
- **Data and operations:** PostgreSQL, Redis, admin workflows, and practical data models that support reliable systems.
- **Desktop and tooling:** Electron apps, terminal-native utilities, scripts, and lower-level tools when the browser is not enough.
- **Visual systems:** motion, 3D, and interface polish that supports the product goal instead of hiding it.
